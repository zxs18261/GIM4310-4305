# 03 软件设计与外设配置（DEMO 外设自检例程）

> 工程路径：`DEMO\1、DEMO`
> 目标：在 CubeMX 生成的框架上，实现一个**外设自检例程**，逐项验证
> 电流采样、母线电压、NTC 温度、磁编码器角度、PWM/MOS、串口 VOFA+、RGB、CAN。

---

## 2. 时钟配置

| 节点 | 值 |
|---|---|
| 上电默认（CubeMX） | HSI16 → PLLM=DIV4 ×PLLN=85 /PLLR=DIV2 = **170MHz** |
| 运行时切换（BSP_CLOCK） | HSE 20MHz → PLLM=DIV5 ×PLLN=85 /PLLR=DIV2 = **170MHz** |
| AHB/HCLK/APB1/APB2 | 170MHz（不分频） |
| ADC12 时钟 | SYSCLK 170MHz，`ADC_CLOCK_SYNC_PCLK_DIV4` → 42.5MHz |
| FDCAN 时钟 | PCLK1 170MHz |

> 切 HSE 目的：HSI ±1% 精度对 1Mbps CAN 位时序裕量不足。切换失败自动回退 HSI 并告警。

## 3. 外设配置与引脚映射

### 3.1 引脚总表

|---|---|---|---|
| U/V/W 上桥 | PA8 / PA9 / PA10 | TIM1_CH1/2/3 (AF6) | FD6288 HIN |
| U/V/W 下桥 | PB13 / PB14 / PB15 | TIM1_CH1N/2N/3N (AF6/AF4) | FD6288 LIN |
| RGB 数据 | PA0 | TIM2_CH1 (AF1) | WS2812 |
| 编码器 CSN | PB4 | GPIO 输出 | 软件 SPI |
| 编码器 CLK | PB5 | GPIO 输出 | 软件 SPI |
| 编码器 DO | PB6 | GPIO 输入 | 软件 SPI |
| 相电流 U | PB1 | OPAMP3_VOUT / ADC1_IN12 | 注入组 rank1 |
| 相电流 V | PA6 | OPAMP2_VOUT / ADC2_IN3 | ADC2 注入组 rank1 |
| 母线电流 | PA2 | OPAMP1_VOUT / ADC1_IN3 | 注入组 rank2 |

| SWD | PA13 / PA14 | SYS | CN9 |

### 3.2 OPAMP（内部运放电流采样）

三路 `OPAMP_STANDALONE_MODE`，`InternalOutput=DISABLE`（输出走外部引脚再由 ADC 采样），
`InvertingInput=IO0 / NonInvertingInput=IO0`，工厂微调。
BSP_ADC_Init 中执行 `HAL_OPAMP_Start()` 启动（仅 CubeMX Init 不够）。

- 增益由外部反馈网络决定，**实物 24 倍**；
- 电流分辨率 `BOARD_CUR_LSB = 3.3 / 4096 / (24 × 0.005) ≈ 6.714 mA/LSB`；
- 零点偏置上电实测（`BSP_ADC_MeasureOffsets`，封波状态平均 256 次）。

### 3.3 ADC

| ADC | 组 | 通道序列 | 触发 | 采样时间 |
|---|---|---|---|---|
| ADC1 | 注入 | rank1=CH12(U相电流), rank2=CH3(母线电流), rank3=CH11(母线电压) | TIM1_TRGO2(OC4) 上升沿，20kHz | 电流 6.5cyc / 母线 24.5cyc |
| ADC1 | 规则 | rank1=CH14(MOS NTC) | 软件 | 247.5cyc |
| ADC2 | 注入 | rank1=CH3(V相电流) | TIM1_TRGO2 上升沿 | 6.5cyc |
| ADC2 | 规则 | rank1=CH5(电机 NTC) | 软件 | 247.5cyc |

- 12bit 右对齐，单端，`ADC_CLOCK_SYNC_PCLK_DIV4`；
- ADC1 JEOS 中断即电流环节拍（`BSP_ADC_IRQHandler`），换算后更新全局测量；
- 规则组（NTC）在后台主循环软件触发轮询，**严禁 HAL_ADC_Stop**（会连带停止注入组）。

### 3.4 TIM1（PWM）

| 项 | 值 |
|---|---|
| 模式 | 中心对齐 1（`TIM_COUNTERMODE_CENTERALIGNED1`） |
| PSC / ARR | 0 / 4250 → PWM 频率 = 170M/(2×4250) = **20kHz** |
| 通道 | CH1/2/3 = 上桥 PWM1；CH1N/2N/3N = 下桥互补 |
| CH4 | PWM2，CCR4 = ARR-40，作为 ADC 注入触发（TRGO2=OC4REF） |
| 死区 | DTG=34（约 200ns @ tDTS=5.88ns）+ FD6288 内部死区 |
| 封波 | `MOE`：`BSP_PWM_Enable/Disable`；**必须用 `__HAL_TIM_MOE_DISABLE_UNCONDITIONALLY`** |

### 3.5 TIM2（WS2812）

PSC=0，ARR=211 → 位周期 1.25µs（800kHz）；CH1(PWM1) 输出到 PA0；
DMA1_Channel3 字传输刷新 CCR1；0 码 CCR=58，1 码 CCR=136；帧尾 80 个 0 时隙 reset。

### 3.6 FDCAN1

经典 CAN 模式，内核时钟 170MHz，位时序查表：

| 波特率 | Prescaler | Seg1 | Seg2 | SJW | 采样点 |
|---|---|---|---|---|---|
| 1 Mbps | 5 | 29 | 4 | 4 | 88.2% |
| 500 kbps | 10 | 29 | 4 | 4 | 88.2% |
| 250 kbps | 20 | 29 | 4 | 4 | 88.2% |
| 125 kbps | 40 | 29 | 4 | 4 | 88.2% |

- 硬件滤波：仅接收本节点 ID 与广播 ID(0x000) 到 FIFO0；
- RX FIFO0 中断内取帧回调；TX 入 TX FIFO 非阻塞；
- **120Ω 终端**：`BSP_CAN_SetTermination(1)` → EN_120 拉高接通。

### 3.7 USART3（VOFA+）

- 921600，8-N-1，PCLK1，无硬件流控；
- TX：DMA1_Channel2 + 2048B 环形缓冲，非阻塞；RX：RXNE 中断入 256B 环；
- VOFA+ 使用 **JustFloat** 协议：12 个 float（小端）+ 帧尾 `0x7F800000`；
- **波特率三处同步**（务必一致，否则上位机无数据）：
  1. `GIM4310(V0.0).ioc`：`USART3.BaudRate=921600`
  2. `Core/Src/usart.c`：`huart3.Init.BaudRate = 921600`（CubeMX 生成处）
  3. `BSP/board_config.h`：`BOARD_UART_BAUDRATE (921600UL)`（BSP 运行时重配）
  上电 banner 会打印实际 `BRR`（正常约 `0x0B87`，对应 170MHz/921600），可用于自检。
- **输出模式**：默认只发 JustFloat 二进制帧（500Hz），周期性文本打印关闭，
  避免文本字节混入二进制帧导致 VOFA 无法解析；命令 `v` 可在
  “数据流模式 / 1Hz 文本模式”之间切换。

### 3.8 中断优先级（NVIC_PRIORITYGROUP_4）

| 中断 | 优先级 |
|---|---|
| ADC1_2（电流环） | 1 |
| FDCAN1_IT0 | 3 |
| USART3 | 6 |
| DMA1_Channel2（UART TX） | 7 |
| DMA1_Channel3（WS2812） | 8 |
| SysTick | 15 |

## 5. 自检例程行为（main.c）

初始化顺序（`APP_Init`）：

1. `BSP_CLOCK_SwitchToHse()`（失败回退 HSI）
2. `BSP_UART_Init()` + VOFA 初始化，打印启动信息
3. `BSP_PWM_Init()`（计数器运行、保持封波，提供 ADC 触发）
4. `BSP_ADC_Init()` + `BSP_ADC_MeasureOffsets(256)` 标定零流偏置
5. `BSP_ENC_Init()` + 延时 35ms + `BSP_ENC_Preload()`
6. `BSP_CAN_Init(CAN_BAUD_1M, 1)`（默认接入 120Ω）
7. `BSP_WS2812_Init()`（初始化完成亮绿色）
8. `BSP_ADC_StartFocIrq(NULL)`（开启 20kHz 数据采集节拍）

主循环（`APP_Loop`）持续执行：
- 读取编码器、电流、母线电压、温度；
- 每 2ms 通过 VOFA+ JustFloat 上报 12 通道数据（可用命令 `v` 切换为文本模式）；
- 每 1s 打印一次状态（含偏置、温度、编码器状态、CAN 计数、电流环计数）；
- 每 200ms 发送一帧 CAN 测试数据（ID=1，`0x55 0xAA` 序号）；
- 每 700ms 循环切换 RGB 颜色（红→绿→蓝→白→黄→青→紫→灭）；
- 收到串口命令时执行对应动作。

串口命令：

| 命令 | 动作 |
|---|---|
| `e` / `E` | 使能开环 PWM（8% 幅值、1Hz 旋转电压矢量，验证发波与 MOS 开关） |
| `d` / `D` | 封波（MOE=0） |
| `t` / `T` | 切换 CAN 120Ω 终端 |
| `s` / `S` | 立即发送一帧 CAN |
| `c` / `C` | 切换到下一种 RGB 颜色 |

## 6. 相对参考例程（5.FOC开环）的关键修改

| 项 | 参考工程 | 本工程 |
|---|---|---|
| 电流采样电路 | 外置四运放，增益 20，信号进 ADC 引脚 | **MCU 内部 OPAMP1/2/3**，增益 **24**（实物电阻） |
| BSP_ADC | 直接采样 PA0~PA3 | 启动 OPAMP + 注入组重配 + 偏置实测 |
| 编码器 | 硬件 SPI1 + 软件片选（MT6816） | **软件 SPI（GPIO 位带）** MT6701（PB4/5/6） |
| CAN | 无 | 新增 `bsp_can.c/.h`，含 120Ω 终端控制 |
| RGB | 地址灯 TIM2+DMA | 同方案，独立 `bsp_ws2812` |
| 串口 | USART3 921600 JustFloat | 同，独立 `bsp_uart`+`bsp_vofa` |
| 时钟 | HSE 8MHz | **HSE 20MHz**（板载晶振） |

## 8. CubeMX `.ioc` 完善说明与已知偏差

已在 `.ioc` 中完善：编码器 PB4/PB5/PB6、USART3 波特率 921600、
TIM1 中心对齐/ARR=4250/死区 34、TIM2 ARR=211、FDCAN 位时序、NVIC 各中断使能。

> **重要设计约定**：与板级强相关的复杂配置（ADC 注入组、DMA 请求、OPAMP 启动、
> PWM 触发等）由 **BSP 层在运行时统一重配**，`.ioc` 与 `Core` 生成代码中的对应项
> 仅作占位/记录。这样即使日后用 CubeMX 重新生成，BSP 仍能保证外设工作一致。
> 后续若需要“纯 CubeMX 配置即完整”，可按本文档第 3 节逐项在 CubeMX 中补齐
> （重点是 ADC 注入组 + TIM1 TRGO2 + DMA）。
