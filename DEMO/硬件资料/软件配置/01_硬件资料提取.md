## 1. 系统概述

| 项目 | 内容 |
|---|---|
| 产品 | GIM4310 / GIM4305 关节电机控制器（伺泰威） |
| 主控 | STM32G431CBU6（Cortex-M4，UFQFPN48，170MHz，128KB Flash / 32KB RAM） |
| 功率级 | 三相全桥，6× MOSFET（MCG53N06AHE3-TP），由 FD6288Q 三相栅极驱动器驱动 |
| 电流采样 | 3× 5mΩ 采样电阻 + **MCU 内部 OPAMP1/2/3 差分放大**（外部反馈网络，实焊增益 24） |
| 位置反馈 | MT6701QT-STD 磁编码器（SSI/SPI，14bit，板载磁铁） |
| 母线电压 | 电阻分压（R23 100k / R22 4.3k）→ ADC |
| 温度 | 板载 MOS NTC（10k，B=3950）+ 电机内置 NTC（经 P3 接口） |
| 通信 | 1× CAN（TJA1051TK/3 收发器 + TS5A3159 切换 120Ω 终端）+ 1× 调试串口 |
| 指示灯 | 1× WS2812 类可寻址 RGB（XL-3528 封装）+ 1× 电源指示 LED |
| 供电 | 24V 母线输入（设计最大 80V）；片上 DC-DC 产生 12V / VCC(5V) / AVCC(3.3V) |
| 调试/烧录 | CN9（6P，1.25mm）：GND / VCC / RX / TX / CLK / DIO（SWD + 串口） |
| 晶振 | 20MHz 无源晶振（X1，C19/C20=10pF，R46=1M） |

> 注意：**板载晶振为 20MHz（非常见 8MHz）**，且 CubeMX 默认按 HSI 运行，
> 固件在启动后切换到 HSE 20MHz 以满足 CAN 位时序精度。

## 3. 主要功能电路

### 3.1 功率级与栅极驱动

- 三相全桥 Q1~Q6：MCG53N06AHE3-TP（N 沟道，60V）。
- 栅极驱动器 U2：**FD6288Q**（三相半桥驱动，输入同相；内部含死区约 100~300ns）。
  - 上桥输入 HIN_U/V/W ← PA8/PA9/PA10（TIM1_CH1/2/3）
  - 下桥输入 LIN_U/V/W ← PB13/PB14/PB15（TIM1_CH1N/2N/3N）
  - 自举：D1/D2/D3（1N4148WS）+ C30/C31/C32（10uF），VBU/VBV/VBW 自举电源。
- 相输出 U/V/W → 电机接线端 P1/P4（U）、P5? 实际相端：P4=U、P1=V、P2=W（网表）。

### 3.2 电流采样（内部 OPAMP，重点）

采用三路 **5mΩ 低侧采样电阻**：

| 通道 | 采样电阻 | 输入到 OPAMP | OPAMP | MCU 端口 | ADC 通道 |
|---|---|---|---|---|---|
| U 相电流 IU | R1 | IU+ / IBUS+ | OPAMP3 | PB1 (VOUT) | ADC1_IN12 |
| V 相电流 IV | R2 | IV+ / IBUS+ | OPAMP2 | PA6 (VOUT) | ADC2_IN3 |
| 母线电流 IBUS | R3 | IBUS+ / PGND | OPAMP1 | PA2 (VOUT) | ADC1_IN3 |

**差分放大电路拓扑**（以 OP3 为例，其余相同）：

```
IU+ ──R37(1k)──┬── OP3_VINP ──── R40(10k) ── AVCC
               │                R41(10k) ── AGND
IBUS+ ─R38(1k)─┴── OP3_VINM ──┬── R39(反馈) ── OP3_VOUT
                              └── (经 OPAMP 内部)
```

- **增益 = R_f / R_in**。原理图丝印标注 `R39/R34/R44 = 25kΩ`、输入电阻 `1kΩ` → 标称增益 **25**；
- **实物反馈电阻焊接值为 24kΩ** → 实际增益 **24 倍**（本工程 `BOARD_CSA_GAIN = 24.0f`）；
- 偏置：VINP 侧由 10k/10k 分压得到约 AVCC/2 ≈ 1.65V（理论对应约 2048 LSB），
  实际偏置受电阻误差影响，固件在封波状态下**上电实测标定**。

电流换算公式（12bit，VREF=3.3V，增益 G，采样电阻 Rs）：

```
I [A] = (raw - offset) * VREF / (4096 * G * Rs)
      = (raw - offset) * 3.3 / (4096 * 24 * 0.005)
      ≈ (raw - offset) * 6.714e-3   [A/LSB]
```

- **分辨率 ≈ 6.71 mA/LSB**（增益 25 时为 6.45 mA/LSB）；
- 半量程量程 ≈ ±13.75 A（受偏置与放大器摆幅限制）。

### 3.3 母线电压采样

- 分压：VBUS ── R23(100k) ──┬── ADC_VBUS(PB12)
                           └── R22(4.3k) ── GND
- 分压比 = (100 + 4.3) / 4.3 = 24.256；
- 分辨率 ≈ 3.3 / 4096 × 24.256 ≈ **19.54 mV/LSB**，满量程 ≈ 80V。

### 3.4 NTC 温度采样

- MOS 管温度：VCC ── R17(10k) ──┬── ADC_MOS_NTC1(PB11) ── NTC2(10k, B=3950) ── GND
- 电机温度：VCC ── R18(10k) ──┬── ADC_MOT_NTC2(PC4) ── 电机 NTC(P3) ── GND
- 两路均为“上拉接电源 + NTC 对地”，比值式测量，β 方程换算：
  `R_ntc = Rp·raw/(N−raw)`，`1/T = 1/T25 + ln(R/R25)/B`。

### 3.5 MT6701 磁编码器

- U15 = MT6701QT-STD，QFN-16；磁铁安装在电机轴中心（“芯片需对准磁铁中心”）。
- SSI 接口：CSN(PB4)、CLK(PB5)、DO(PB6)；MODE 引脚决定 SSI/ABZ 等模式。
- 输出 24bit 帧：`D[13:0] 角度 + Mg[3:0] 磁场状态 + CRC[5:0]`（CRC6：X⁶+X+1）。
- 单圈分辨率 14bit = 16384。

### 3.6 CAN 通信与 120Ω 终端

- 收发器 U9 = TJA1051TK/3：TXD(PA12)、RXD(PA11)；CAN_H / CAN_L 经 XT30 连接器 U4/U5。
- 终端电阻切换：**U10 = TS5A3159** 模拟开关，
  - `NO` → R21(120Ω) → CAN_H；`COM` → CAN_L；`IN` → EN_120(PA15)；
  - **EN_120 = 高电平** 时开关导通，在 CAN_H / CAN_L 之间接入 120Ω。
- 保护：D4 = SMBJ36CA TVS，R19=0Ω，C24/C26/C27/C28 滤波。

### 3.7 RGB 指示灯

- LED1 = 4 脚可寻址 RGB（WS2812 类，GRB 序）；DIN ← PA0（TIM2_CH1），5V 供电。
- 另有 LED2 = GL0603UR01 电源指示灯（常亮）。

### 3.8 电源

- U1 = LMR16006XDDCR（2.1MHz，VFB=0.765V，R20/R24 100k 分压 → 12V）
- U6/U7/U8 = SSP9481 / HI9205 等 DC-DC（产生 VCC / 12V / 3.3V）
- U16 = ME6231A33M3G（3.3V LDO）

## 5. 数据手册要点

- **STM32G431CBU6**：Cortex-M4F @170MHz，集成 3× 运放（可接外部反馈网络构成差分放大）、
  2× 12bit ADC（支持注入组硬件触发，适合电机电流同步采样）、FDCAN、DAC、比较器等。
- **MT6701**：14bit 磁角度传感器，支持 SSI/SPI/ABZ/PWM；SSI 帧 24bit 含 CRC6 与磁场告警。
- **FD6288Q**：三相 600V 半桥驱动，输入同相，内置死区与欠压保护。
- **MCG53N06AHE3-TP**：60V / 低导通电阻 N-MOS。
- **TS5A3159**：单刀双掷模拟开关，用于 120Ω 终端投入/切出。

## 6. 硬件关键注意事项（移植/调试必读）

1. **电流采样用 MCU 内部运放**，与常见外置运放方案不同；BSP_ADC 必须按内部 OPAMP + 注入组重写。
2. **增益按实物取 24**（原理图标注 25，实物 24kΩ）。
3. **编码器必须软件 SPI**（PB4/PB5/PB6），不要使用 CubeMX 的 SPI1 映射。
4. **EN_120 高电平接入 120Ω**，CAN BSP 单独实现终端控制。
5. **晶振 20MHz**，建议切 HSE 以提高 CAN 1Mbps 时序裕量。
6. **FD6288 输入同相**，TIM1 CH1/2/3 为上桥、CH1N/2N/3N 为下桥，死区需软硬件叠加理解。
7. **PA15/PC13~PC15 属于特殊电源域引脚**，本板 PA15 仅作 EN_120 电平控制。
