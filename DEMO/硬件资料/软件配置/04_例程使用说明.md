# 04 例程使用说明

> 对应工程：`DEMO\1、DEMO`（外设自检例程）

---

## 1. 硬件连接

| 用途 | 接口 | 说明 |
|---|---|---|
| 调试串口（VOFA+） | CN9 或 PB9(TX)/PB8(RX) | 921600，8-N-1 |
| SWD 烧录 | CN9 CLK/DIO 或 PA14/PA13 | — |
| CAN | XT30（CAN_H / CAN_L） | 默认启用 120Ω 终端；总线两端各一个 120Ω |
| 电机三相 | U/V/W | 自检时可不接电机 |
| 编码器 | 板载 MT6701 | 需磁铁对中 |
| 电源 | XT30 | 母线 24V（注意电压范围） |

---

## 2. 上电自检流程

1. 上电后串口输出启动信息与 `init done`；
2. RGB 灯初始化完成亮**绿色**，随后按周期循环变色；
3. 串口每 1s 打印一次状态，如下示例：

```
===== GIM4310/4305 DEMO STATUS =====
clock        : HSE 20MHz
adc offset   : Iu=2048 Iv=2048 Ibus=2048 [LSB]
current      : Iu=+0.001 Iv=-0.002 Ibus=+0.000 A (sat=0)
vbus         : 24.05 V
temp         : MOS=32.4 C  MOTOR=31.8 C
encoder      : raw=12345 turns=0 status=0 crc_err=0 field_err=0
pwm          : ENABLED  duties=0.56/0.44/0.50
can          : rx=0 err=0 term=1 lastId=0x000
foc irq cnt  : 205413
cmd: e/d/a/f/t/s/c/r/?
```

> 串口命令：`e` 使能开环、`d` 封波、`a` 切幅值（3/6/9/15/25%）、`f` 切频率、`t` 切 CAN 终端、
> `s` 发送 CAN、`c` 切 RGB 颜色、`r` 重新标定 ADC 零点、`v` 切换 VOFA 数据流/文本模式、
> `?` 立即打印状态。

---

## 3. VOFA+ 上位机设置

1. 打开 VOFA+，新建工程，选择数据源为串口，端口选对应 COM，波特率 **921600**；
2. 协议选择 **JustFloat**；
3. 通道数 12，含义（详见 `05_外设测试手册_VOFA.md`）：

> **输出模式**：固件默认 `vofaStreamOn=1`，即**只发送 JustFloat 二进制帧（500Hz），不输出任何周期性文本**，
> 以保证 VOFA+ 解析稳定。需要看文本状态时发送命令 `v` 关闭数据流，即恢复 1Hz 文本打印；
> 再发 `v` 可切回数据流模式。
> 波特率在三处保持一致：`GIM4310(V0.0).ioc` 的 `USART3.BaudRate=921600`、
> `Core/Src/usart.c` 的 `huart3.Init.BaudRate = 921600`、
> `BSP/board_config.h` 的 `BOARD_UART_BAUDRATE (921600UL)`。


| 通道 | 含义 | 单位 |
|---|---|---|
| ch0 | Iu（U 相电流） | A |
| ch1 | Iv（V 相电流） | A |
| ch2 | Ibus（母线电流） | A |
| ch3 | Vbus（母线电压） | V |
| ch4 | 转子机械角（单圈） | ° |
| ch5 | 电角度（×14） | ° |
| ch6 | U 相占空比 | 0~1 |
| ch7 | V 相占空比 | 0~1 |
| ch8 | W 相占空比 | 0~1 |
| ch9 | MOS 温度 | ℃ |
| ch10 | 电机温度 | ℃ |
| ch11 | CAN 接收计数 | — |
| ch12 | W 相电流（重构 `-(Iu+Iv)`） | A |

## 4. 逐项验证方法

| 项目 | 验证方法 | 预期现象 |
|---|---|---|
| 电流采样 | 串口状态 `current` / VOFA ch0~ch2 | 零流时接近 0A（偏置标定后）；`adc offset` 约 1500~2500 LSB |
| 母线电压 | VOFA ch3 / 状态 `vbus` | 与实际母线电压一致（误差 <2%） |
| NTC 温度 | 状态 `temp` | 室温约 25~35℃；短路/开路返回 250 |
| 磁铁角度 | 状态 `encoder` / VOFA ch4 | 转动电机时角度连续变化，`crc_err`/`field_err` 不增长 |
| PWM 发波 | 发送 `e` 使能后示波器测 PA8/PA9/PA10 与 PB13/14/15 | 20kHz 中心对齐互补方波，死区约 200ns；`d` 封波后全低 |
| MOS 开关 | 使能开环后相端对地电压 | 三相正弦调制（8% 幅值） |
| 串口 VOFA | 打开 VOFA+ JustFloat | 12 通道数据实时刷新 |
| RGB 灯 | 观察或发送 `c` | 红/绿/蓝/白/黄/青/紫/灭 循环 |
| CAN 通讯 | 连接 CAN 分析仪，或自测（`t` 切换终端、`s` 发送） | 可收到 ID=1 周期帧；接收计数 `rx` 增长 |

---

## 5. 注意事项 / 安全

1. **开环 PWM 测试**默认关闭；按 `e` 使能后为 8% 幅值、1Hz 电频率，属于安全演示级别，
   但**务必确认母线电压与接线正确**后再使能；按 `d` 立即封波。
2. 电流采样量程约 ±13.75A，超出会导致运放/ADC 饱和（状态 `sat=1`）。
3. 编码器为软件 SPI，读取约 5µs/次；若 `crc_err` 持续增长，检查 PB4/PB5/PB6 接线与磁铁位置。
4. CAN 终端电阻：仅总线两端节点启用；可通过 `t` 命令切换。
5. 串口 921600 需终端/上位机支持；不支持时可改 `board_config.h` 的 `BOARD_UART_BAUDRATE`。
6. 首次上电建议**先不接电机**，确认电流零点、温度、编码器正常后再接。
