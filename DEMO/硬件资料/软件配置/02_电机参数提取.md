## 2.3 固件使用的关键参数

| 参数 | 取值 | 用途 |
|---|---|---|
| 极对数 Pole pairs | 14 | 电角度 = 机械角 × 14 |
| 编码器分辨率 | 16384（14bit） | MT6701 单圈计数、角度换算 |
| 减速比 Gear rate | 10:1 | 输出轴角度 = 转子角度 / 10 |
| 额定/峰值电流 | GIM4310: 2.1 / 15.3 A；GIM4305: 2.0 / 19.55 A | 电流环限幅、过流保护阈值参考 |
| 线电阻线电感 | GIM4310: 1.96Ω / 668.47mH；GIM4305: 1.11Ω / 283.96mH | 电流环 PI 参数整定（`Kp=Ls·ωc`，`Ki=Rs·ωc·Ts`） |
| 扭矩常数 | GIM4310: 0.78；GIM4305: 0.5 N·m/A | 电流↔转矩换算 |

> 说明：表中“额定电压 48V”与“电压范围 12~40V”为原图数据，可能存在页面标注不一致，
> 实际按母线电压范围设计（设计最大 80V，见原理图注释“额定 24V，设计最大输入 80V”）。
