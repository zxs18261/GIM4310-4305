## 关键设计结论（速览）

1. 电流采样使用 **MCU 内部 OPAMP1/2/3** 差分放大，增益按实物 **24**（非原理图标注 25）。
2. MT6701 编码器 **必须软件 SPI**（CSN=PB4 / CLK=PB5 / DO=PB6，无硬件 SPI 复用）。
3. CAN 终端电阻由 **EN_120（PA15）** 控制，120Ω 单独 BSP（`bsp_can.c/.h`）实现。
4. 晶振为 **20MHz**，运行时切 HSE 提升 CAN 时序精度。
5. 参考工程 `1_AxDr_Demo\1.basic代码\5.FOC开环`，本工程在其功能划分基础上按本板硬件重写 BSP。
