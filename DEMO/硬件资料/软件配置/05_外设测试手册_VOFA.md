# 05 外设测试手册（以 VOFA+ 为主要观测手段）

> 对应工程：`DEMO\1、DEMO`（外设自检例程）
> 目标：用 VOFA+ 上位机配合示波器/终端，逐项验证各外设是否正常。
> 固件一旦运行即持续以 500Hz 通过 USART3（921600）发送 12 通道 JustFloat 数据，
> 无需额外配置即可开始观察。

---

## 0. 准备工作

| 项 | 内容 |
|---|---|
| 固件 | 编译 `MDK-ARM\GIM4310(V0.0).uvprojx` 并烧录 |
| 串口 | USB-TTL，接 CN9 的 TX/RX/GND（或 PB9=TX、PB8=RX）；波特率 921600，8-N-1 |
| 上位机 | VOFA+（下载地址以官网为准），选择串口数据源 |
| 示波器 | 4 通道，用于观察 PWM/MOS（可选但推荐） |
| CAN 工具 | USB-CAN 分析仪（可选） |
| 电源 | 母线 24V（先不接电机，确认基础功能后再接） |

---

## 1. VOFA+ 配置（关键）

1. 打开 VOFA+ → 新建工程 → 数据源选 **串口**，选择对应 COM 口；
2. 波特率设为 **921600**，数据位 8，停止位 1，无校验，无流控；
3. 解析协议选 **JustFloat**（不要选 FireWater/RawData）；
4. 通道数默认由数据自动识别；本工程为 **12 通道**；
5. 固件默认**只发 JustFloat 帧、不发文本**，因此波形应直接稳定出现；
   需要看文本时在 VOFA 的 RAW/命令栏发送 `v`，固件切到 1Hz 文本模式，再发 `v` 切回。
5. 建议添加以下控件（拖到画布）：
   - **波形图（Wave）**：拖入 ch0(电流)、ch3(母线电压)、ch4/ch5(角度)、ch6~ch8(占空比)；
   - **仪表盘/数值（Value）**：ch3 电压、ch9/ch10 温度、ch11 CAN 计数；
   - **按键（Button，发送 ASCII）**：发送 `e`/`d`/`a`/`f`/`t`/`s`/`c`/`r`/`?` 命令。

### 12 通道含义（务必对照）

| 通道 | 名称 | 单位 | 说明 |
|---:|---|---|---|
| ch0 | Iu | A | U 相电流（内部 OPAMP→ADC1_IN12） |
| ch1 | Iv | A | V 相电流（OPAMP2→ADC2_IN3） |
| ch2 | Ibus | A | 母线电流（低侧采样时刻≈0，仅诊断） |
| ch3 | Vbus | V | 母线电压 |
| ch4 | rotor | ° | 转子机械角（单圈，0~360） |
| ch5 | elec | ° | 电角度（机械角×14 取模） |
| ch6 | dutyU | 0~1 | U 相高侧占空比 |
| ch7 | dutyV | 0~1 | V 相高侧占空比 |
| ch8 | dutyW | 0~1 | W 相高侧占空比 |
| ch9 | Tmos | ℃ | MOS 管 NTC 温度 |
| ch10 | Tmot | ℃ | 电机 NTC 温度 |
| ch11 | canRxCnt | — | CAN 接收帧计数 |
| ch12 | Iw | A | W 相电流（软件重构 `Iw = -(Iu+Iv)`，三线制） |

> 终端里同时每 1s 打印一次完整状态文本（含零点、编码器状态、错误计数等），
> 可与 VOFA 图形互为补充。

## 2. 逐项测试步骤

### 2.1 串口 / VOFA 链路

1. 上电，VOFA 波形应立即出现 12 条曲线；
2. ch3 稳定在母线电压附近，ch11 若接了 CAN 会缓慢增长；
3. **通过标准**：数据连续、无断帧、波特率错误时会出现乱码或卡顿。
4. 若 VOFA 无数据：检查 COM 口、921600、JustFloat、接线 TX/RX 是否交叉。

### 2.2 电流采样（内部 OPAMP，增益 24）

测试分两步：**零点（偏置）** 与 **动态电流**。

**A. 零点标定校验（不接电机）**
1. 上电后看终端 `ADC zero offset: Iu=... Iv=... Ibus=... [LSB]`；
2. 理论值 = 1.65V/3.3V×4096 ≈ **2048 LSB**，实测应在 **1500~2500** 之间；
3. VOFA ch0/ch1 应接近 **0.000A**（噪声 ±0.02A 内）；
4. 若执行了其他操作导致漂移，发送 `r` 重新标定；
5. **通过标准**：零点在合理范围，静止时电流≈0。

**B. 动态电流（接电机或电阻负载）**
1. 将电机三相接到 U/V/W（先不固定，注意安全）；
2. 发送 `e` 使能开环（默认 6% 幅值、1Hz 电频率，可 `a`/`f` 调整）；
3. 观察 VOFA ch0/ch1：应为**相位差约 120° 的正弦波**，幅值与负载有关；
4. ch6~ch8 的占空比也应为 120° 相位差的正弦（0.5±幅值）；
5. **通过标准**：三相电流正弦、相位正确、无削顶；`sat=0`（未饱和）。
6. 若无法接电机，可用功率电阻跨接两相并在开环下观察电流；
   也可用钳形表/电流探头对比 ch0 的数值。

### 2.3 母线电压采样

1. VOFA ch3 与万用表实测母线电压对比；
2. 换算：`Vbus = raw × 19.54mV`；24V 时 raw≈1228；
3. **通过标准**：误差 < 2%（约 ±0.5V @24V）；
4. 若偏差大：检查 R23(100k)/R22(4.3k) 是否与原理图一致、`BOARD_VBUS_R_TOP/BOT` 是否匹配。

### 2.4 NTC 温度采样

1. VOFA ch9(MOS)、ch10(电机) 与室温对比；
2. 室温 25℃ 时，NTC 阻值≈10k，与 10k 上拉分压 → raw≈2048，温度≈25℃；
3. 用手捏住 NTC（或接一个已知电阻）验证读数上升/下降；
4. **通过标准**：两路温度均在室温±5℃内，且随温度变化趋势正确；
5. 若读到 **250℃**：表示传感器开路/短路（P3 未接电机 NTC 时属正常）。
6. 电机 NTC 的 B 值未公开，如需精确可实测标定后改 `BOARD_NTC_MOT_BETA`。

### 2.5 磁编码器（MT6701，软件 SPI）

1. VOFA ch4(机械角) 与 ch5(电角度)；
2. 手动缓慢转动电机轴：ch4 应在 **0~360°** 线性单调变化，转过一圈后回绕；
3. 观察终端 `encoder: raw=... status=0 crc_err=... field_err=...`；
4. **通过标准**：
   - `status=0`（OK），`crc_err`/`field_err` 不增长；
   - ch4 转动时连续，无跳变/卡死；
   - 每机械圈 raw 变化 16384（14bit）。
5. 若 `crc_err` 持续增长 → 检查 PB4/PB5/PB6 接线与电平；
   若 `field_err` → 磁铁位置偏或磁场过强/过弱（调整磁铁对中）。
6. 角度方向反了（ch4 随正转变小）：可调用 `BSP_ENC_SetInvert(1)`（或后续上电校准）。

### 2.6 PWM 发波 / MOS 开通关断

**A. 逻辑观察（VOFA）**
1. 发送 `e`，VOFA ch6~ch8 出现三路 120° 相位差的正弦（幅值 = 设定档位）；
2. 发送 `a` 切换幅值（3%/6%/9%），发送 `f` 切换频率（0.5/1/2/5Hz），曲线随之变化；
3. 发送 `d` 后 ch6~ch8 变为 0，输出封波。

**B. 示波器观察（关键）**
1. 探头接上桥输入 PA8/PA9/PA10 与下桥输入 PB13/PB14/PB15（或相端对 PGND）；
2. 使能后应看到 **20kHz 中心对齐互补 PWM**，高/低侧之间有明显死区（约 200ns + FD6288 内部死区）；
3. 相端（U/V/W 对 PGND）应为 SPWM 正弦调制波形（8% 档约 3~13% 占空比区间）；
4. 封波 `d` 后六路输入应全为低（FD6288 输入下拉），MOS 全部关断；
5. **通过标准**：频率 20kHz、互补、死区正常、封波可靠。
6. 无示波器时：可用 VOFA 占空比间接确认发波逻辑，但**无法验证实际电气输出**，
   建议至少用万用表测相端平均电压随占空比变化。

> 安全：开环测试务必确认母线电压与接线；默认幅值 ≤9%，属安全演示级别；
> 异常时立即发送 `d` 或断开母线。

### 2.7 RGB 灯（WS2812）

1. 上电初始化完成 → **绿色**；
2. 未使能开环时每 700ms 自动循环：绿→红→蓝→白→黄→青→紫→灭；
3. 发送 `c` 手动切到下一种颜色；
4. **通过标准**：颜色正确、切换正常、无闪烁/错色（错色多为时序或电平问题）。
5. 若某个颜色不对：检查 WS2812 的 GRB 顺序（`BOARD_WS2812_ORDER_RGB`）
   与位时序（`BOARD_WS2812_CCR_0/1`）；3.3V 驱动 5V 灯余量不足时需加电平转换。

### 2.8 CAN 通讯（含 120Ω 终端）

**A. 自发自收 / 总线观察**
1. 用 USB-CAN 分析仪接 CAN_H/CAN_L，波特率 **1Mbps**；
2. 固件每 200ms 发送一帧：ID=1，数据 `55 AA <序号低> <序号高> <irq低> 00 00 00`；
3. **通过标准**：分析仪能收到周期帧且序号递增；
4. VOFA ch11(canRxCnt) 在收到外部帧时增长。

**B. 终端电阻**
1. 发送 `t` 切换终端；终端 `term` 字段在 0/1 间切换；
2. 测量 CAN_H-CAN_L 直流电阻：`term=1` 时约 60Ω（两个 120Ω 并联，若对端也有终端），
   `term=0` 时约 120Ω（仅对端）；
3. **通过标准**：`t` 能切换，总线电阻相应变化，通信正常。

**C. 总线错误**
1. 观察终端 `can: rx=.. err=..`；`err` 持续增长表示总线错误（波特率不匹配、
   缺少终端、接线反、位采样点不合适）。
2. 单节点自测无对端应答时，可能因无 ACK 而重发（属正常），接上另一节点即可。

## 3. 串口命令速查

| 命令 | 功能 | 备注 |
|---|---|---|
| `e` | 使能开环 PWM | 默认 6%、1Hz；对应 VOFA ch6~ch8 |
| `d` | 封波 | MOE=0，输出高阻 |
| `a` | 循环幅值 **3%/6%/9%/15%/25%** | 幅值越大电流越大，便于观察电流采样 |
| `f` | 切换频率 0.5/1/2/5Hz | 观察电流频率变化 |
| `t` | 切换 CAN 120Ω 终端 | 终端 `term` 字段同步 |
| `s` | 立即发送一帧 CAN | 便于抓包 |
| `c` | 切换 RGB 颜色 | — |
| `r` | 重新标定 ADC 零流偏置 | **必须封波状态下执行** |
| `v` | 切换 VOFA 数据流 / 文本模式 | 默认数据流；切文本后可看 1Hz 状态 |
| `?` | 立即打印状态 | 会短暂打断 JustFloat 波形，正常 |

## 5. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| VOFA 无数据/乱码 | 波特率/协议不对、TX-RX 未交叉 | 921600 + JustFloat；交换 TX/RX |
| 电流零点贴近某一轨（<500 或 >3600 LSB） | **差放偏置网络阻值不匹配**：要求 `R40‖R41 = 反馈 24k`，实物 10k‖10k=5k → 零流输出 6.9V 饱和到正轨 | **硬件整改**：R40/R41、R45/R29、R35/R36 改为 **47k~48k**（详见 `06_调试纪要…md` §五） |
| 电流读数恒≈0、看不出变化 | 同上（偏置贴轨后 `raw-offset≈0`） | 先改偏置电阻；改前电流通道不可用 |
| 电流恒为非零/削顶 | 偏置未标定、电流超出量程 | 封波后 `r` 重新标定；减小负载 |
| 母线电压/母线电流通道恒为 0 | 曾因 `ScanConvMode=DISABLE` 使 ADC1 注入序列退化为 1 通道（已修） | 已修复；若复现请确认 `bsp_adc.c` 中 `hadc1.Init.ScanConvMode = ADC_SCAN_ENABLE` |
| `Ibus` 一直≈0 | **设计如此**：母线回流 shunt 在低侧采样时刻（三相低侧全导通、电流环流）不流过直流母线电流 | 属正常；母线电流仅诊断用，看 `Iu/Iv/Iw` 为准 |
| 母线电压偏差大 | 分压电阻不符 | 核对 R23/R22 与宏定义 |
| 温度读到 250℃ | NTC 未接/开路 | 接上电机 NTC（P3）或属正常 |
| 编码器 crc_err 增长 | 软件 SPI 接线/电平问题 | 检查 PB4/PB5/PB6；缩短连线 |
| 编码器 field_err | 磁铁偏心/磁场弱 | 调整磁铁对中、检查气隙 |
| PWM 无输出 | 未使能、MOE 未开 | 发送 `e`；示波器确认 PA8/9/10、PB13/14/15 |
| RGB 不亮/错色 | 时序/电平/顺序 | 调整 CCR 与 GRB 顺序，必要时电平转换 |
| CAN 不通/err 增长 | 无终端、波特率不符、接线反 | `t` 接入终端；核对 1Mbps 与 CAN_H/L |
| 系统卡死/无打印 | Error_Handler 触发（初始化失败） | 查是否有外设 Init 返回错误；看门狗/复位重试 |

### 排查：VOFA 连上后“完全没有数据”

按以下顺序确认（固件默认已在 921600 且只发 JustFloat）：

1. **先用普通串口终端以 921600 打开**，复位板子，应看到启动 banner：
   ```
   *** GIM4310/4305 peripheral self-test DEMO ***
   SYSCLK=170000000 Hz, source=HSE
   USART3: 921600 bps, BRR=0x0B87, JustFloat 12ch
   >>> VOFA streaming ON (text muted). Send 'v' to switch to text mode.
   ```
   - **看得到** → 波特率正确，问题在 VOFA 设置：确认协议是 JustFloat、通道数自动识别、COM 口正确。
   - **看不到或乱码** → 波特率不对。检查：
     - `.ioc`：`USART3.BaudRate=921600`；
     - `Core/Src/usart.c`：`huart3.Init.BaudRate = 921600`；
     - `BSP/board_config.h`：`BOARD_UART_BAUDRATE (921600UL)`；
     - 若 BRR 打印出来不是 `0x0B87`，说明 USART3 时钟源不是 170MHz（检查 SystemClock_Config 与 HSE 切换）。
2. **确认 TX/RX 交叉**：USB-TTL 的 RX 接板子 TX(PB9/CN9-TX)，TTL 的 TX 接板子 RX(PB8/CN9-RX)，GND 共地。
3. **确认串口未被占用**：CN9 的 RX 与 BOOT0 共享引脚，上电瞬间若 RX 被拉高可能进入 Bootloader；
   建议先上电再连接串口，或确认 TTL 空闲电平为高。
4. **发送 `v`**：若切到文本模式后能看到 1Hz 状态打印，则收发均正常，只是 VOFA 解析问题。
5. **开启 VOFA 的原始数据查看（Raw）**：应能看到以 4 字节 `00 00 80 7F` 结尾的二进制帧，
   出现该帧尾说明数据格式正确。
6. 若按 `?` 后 VOFA 波形出现跳变，属正常（文本混入），随后会自动恢复。

> 说明：本固件刻意将周期性文本打印与 JustFloat 数据流分离（`vofaStreamOn`），
> 避免文本字节混入二进制帧导致上位机长时间无法解析。这通常是“VOFA 无数据”的主要原因。

## 6. 推荐测试顺序（最少硬件）

1. 不接电机上电：串口/VOFA 通路 → 零点 → 母线电压 → 温度 → 编码器 → RGB；
2. 接电机（或电阻负载）：开环 PWM → 电流动态 → 示波器看 PWM/相电压；
3. 接 CAN 分析仪：周期发送/接收 → 终端切换；
4. 全部通过后，再进入 FOC/闭环开发。
