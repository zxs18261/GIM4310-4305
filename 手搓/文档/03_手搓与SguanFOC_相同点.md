# 手搓 FOC 与 SguanFOC Library — 相同点

> 对比对象  
> - **手搓**：`E:\github\GIM4310-4305\手搓\Application\control`（自研固件内嵌 FOC）  
> - **SguanFOC**：`E:\github\GIM4310-4305\SguanFOC库文件编写\SguanFOC_Library-main`（第三方通用库）

二者**不是同一份代码的拷贝**，但在「无刷电机矢量控制」这一层有大量共性。

---

## 1. 控制理论同源

| 共性 | 说明 |
|---|---|
| 磁场定向控制 FOC | Clarke → Park → d/q 电流调节 → InvPark → 三相调制 |
| SVPWM 类调制 | 都将 αβ 电压变成三相占空比（实现手法不同，见《不同点》） |
| 内模 / IMC 电流环思想 | 手搓：`Kp=Ls·ωc`；Sguan 文档亦强调 IMC 整定 |
| 交叉解耦 + 反电势前馈 | 均支持 d/q 解耦与磁链相关前馈（可开关） |
| PLL 估速 | 编码器机械角经 PLL 得到速度，再乘极对数得电角速度 |
| 多环级联 | 电流内环 + 速度环 +（可选）位置环 |
| 开环调试模式 | 均可用电压矢量 / Uq 做相序、方向、摸底测试 |

---

## 2. 软件工程共性

| 共性 | 说明 |
|---|---|
| 纯 C 实现 | 无 C++ 强制依赖，便于嵌入式部署 |
| MIT 许可 | 均可学习、商用（注意各自版权声明） |
| 状态机管理电机生命周期 | 初始化 / 运行 / 故障 / 待机等阶段 |
| 参数与算法分层 | 手搓：`config/` + `control/`；Sguan：`UserData_*` + `Sguan_*` |
| 保护概念 | 过流、母线电压、温度等（阈值与实现深度不同） |
| 需要编码器（有感路径） | 手搓默认有感；Sguan v3.0.x 亦为有感主线 |

---

## 3. 运行时共性

| 共性 | 说明 |
|---|---|
| 高频电流环 + 低频任务 | 手搓：ADC ISR 20kHz + 后台；Sguan：High_Loop + Low_Loop |
| 电流零偏校准 | 上电封波测 ADC offset |
| 电角度依赖磁编 + 极对数 | `θe = θm · PP ± offset`（offset 获取方式不同） |
| 母线电压参与调制限幅 | 占空比 / 电压矢量随 Vbus 动态限制 |

---

## 4. 目标应用重叠

- 关节 / 云台类无刷电机  
- STM32G4 一类 Cortex-M4F（Sguan 例程③即为 G4 双电阻）  
- 需要电流闭环与位置/速度伺服的场景  

---

## 5. 一句话总结相同点

> **都是「有感 FOC + 多环 + 保护 + 串口调试」的嵌入式电机控制实现；数学骨架一致，工程形态不同。**
